# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a collection of supplementary class notes and addenda for high school computer science and technology courses (ICS3U, TEJ4M, CCC). Content is written in Markdown and rendered via GitHub Pages using the Jekyll Primer theme with GitHub Flavored Markdown (GFM).

## Structure

- **ICS3U/**: Grade 11 Computer Science notes — Processing, Java fundamentals, coding style, methods
- **TEJ4M/**: Computer Engineering Technology notes — networking, hardware
- **CCC/**: Canadian Computing Competition prep — Java I/O patterns
- **.media/**: Shared images referenced by notes

## Conventions

- All content files are Markdown (`.md`) using GFM syntax
- Jekyll config (`_config.yml`) uses the `jekyll-theme-primer` theme with no title and no downloads
- Code examples in notes are primarily Java and Processing
- Images go in `.media/` and are referenced with relative paths
