# Installing Linux (Lubuntu) on a Chromebook

## Step 1 — Get set up

Get a Chromebook and AC adapter. Plug into AC power and turn on.

## Step 2 — Identify the firmware

Watch the screen as the machine boots.

- **Chrome logo** (white circle with coloured segments): this machine still has the original Chromebook firmware and is not ready. Return it and get a different one.
- **Rabbit logo**: this machine has coreboot firmware and is ready for the install. Continue to Step 3.

## Step 3 — Open the boot menu

Reboot the machine. When the **rabbit logo** appears, press **Esc** to open the boot menu.

## Step 4 — Plug in the USB drive

Insert the class USB drive (it has Ventoy + the Lubuntu ISO on it).

## Step 5 — Boot from USB

In the boot menu, select the **USB drive** and press **Enter**.

## Step 6 — Ventoy — select and launch the installer

Ventoy loads and shows the available ISOs.

1. Select **Lubuntu.iso**.
2. Choose **Boot in normal mode**.
3. Select **Install Lubuntu**.

## Step 7 — Connect to Wi-Fi and start the installer

Lubuntu loads to a live desktop.

1. Connect to Wi-Fi — SSID: **YCBYOD**.
2. Double-click (or select) **Install Lubuntu** to launch the installer.

## Step 8 — Configure install options

Work through the installer screens:

| Screen | Setting |
|--------|---------|
| **Installation type** | Customize → **Normal Install** |
| **Partitioning** | **Erase Disk** |
| **User account** | Set your name, username, computer name, and password — don't forget these |

Click through to start the install and wait for it to finish (~10 minutes). When prompted, remove the USB drive and restart.

## Step 9 — Verify

After the machine reboots into Lubuntu:

1. Connect to **YCBYOD**.
2. Open **Firefox** and confirm you can browse the web.
