# `_planning/` — Teacher-Facing Materials

This folder holds sequencing, rationale, and lesson-planning detail for TEJ4M — not meant for student eyes, but not sensitive either. Nothing in here is linked from the student-facing `unit-N-.../` pages.

- `unit-N-overview.md` — per-unit arc, period-by-period sequencing, assessment structure, file checklist
- `unit-3-alu-lesson-plans.md`, `unit-4-day*-lesson-plans.md` — detailed day-by-day plans for sections that warrant more than the overview table
- `rpi-network-scan.md` — finding imaged Pi IPs on the school network
- `troubleshooting_solutions.md` — answer key for the Unit 2 troubleshooting exercises
- `cpt-reference-2025/` — archived student robot code from last year's sumo CPT, kept for calibration (see its own README)

## What's deliberately not here

**This repo is public.** Actual test/exam question papers are never committed here, even in a `_planning/` subfolder — that's the one category of content kept out entirely, since a public repo is also readable by current and future students. Unit overviews describe each unit's test (format, mark breakdown, what it draws on) so the structure is documented, but the paper itself lives elsewhere.

Low-stakes material — in-class practice, homework, lab completion checks, and their solutions (e.g. `troubleshooting_solutions.md`, the `practice-*-solutions.md` files in `unit-3-digital-logic/`) — is fine to keep here; the line is drawn at summative test/exam papers specifically.
